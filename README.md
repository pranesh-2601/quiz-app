# Quiz App

A ten-question Flutter quiz about Flutter and Dart basics. It shows progress, locks answers after selection, gives correct/incorrect feedback, scores the attempt, and allows a full restart.

## Run in DartPad

Open [DartPad](https://dartpad.dev/), choose Flutter, paste `lib/main.dart`, then select **Run**.

## Run locally

Install Flutter, then run `flutter pub get` and `flutter run` from this folder.

## Checklist walkthrough

Complete an attempt with all correct answers, all incorrect answers, then a mixed attempt. Confirm that the score matches the number correct, subsequent options are disabled after an answer, progress advances, and Restart returns to question 1 with score 0.
